Saving and sync settings

To add or remove cars from this page, it needs permission to edit your repo. Create a token once per device:

  1. Open GitHub > new fine-grained token.
  2. Repository access: Only select repositories, and choose this repo only.
  3. Permissions: Contents: Read and write and Actions: Read and write.
  4. Pick an expiry, create the token, and paste it below.

The token stays in this browser only. Anyone holding it can edit this repo, so keep it private and don't commit it anywhere.
